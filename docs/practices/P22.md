# P22: Removable example agent

## Problem

A template's example agent is the fastest way to learn the repo and the first thing a fork deletes. If the core code, tests or CI depend on it, deleting it breaks the build, and a fork either keeps dead code or loses the proofs of the practices.

## What the template does

- The core (persistence, worker, observability, policies) imports the agent in one place only, its line in the registry. The worker finds agents through the registry and `APP_EXTRA_AGENTS`.
- The core practices (P8 to P13) are proven on a test-only graph in `tests/graphs/`, so their proofs survive the removal.
- `scripts/remove_example.py` deletes the agent's package and the files that only it uses, removes its `langgraph.json` entry and registry line, resets the settings default that names it, and removes the example's parts of the Makefile, the Dockerfile, CI, the settings with their `.env.example` lines and tests, `compose.yaml` and the Kubernetes manifests. Files mark those parts with `# example-agent:begin` and `# example-agent:end` lines. It prints the `uv remove` command for the example's dependencies.
- The script prints each change, makes a change only where the example's text is still there (a second run changes nothing), and refuses to run outside the repository root. On a first run it refuses, changing nothing, when a file it edits has drifted, or when a recipe or CI step would still call a removed make target.
- The CI `removal` job runs it on a copy of each commit, then the unit tests, lint and typecheck, and checks that no file under `src/` names the agent.

## Where

- `scripts/remove_example.py`
- `.github/workflows/ci.yml`
- `src/langgraph_and_observability/worker/registry.py`
- `langgraph.json`

## Proof

- `tests/unit/test_scripts.py::test_remove_example_in_temp_copy`: the rest of the suite still imports.
- `tests/unit/test_scripts.py::test_remove_example_is_idempotent`
- `tests/unit/test_scripts.py::test_remove_example_refuses_a_drifted_edit_on_the_first_run`
- `tests/unit/test_ci_config.py::test_removal_job_removes_the_example_from_a_copy_then_checks_the_rest`
- `.github/workflows/ci.yml`: the `removal` job.
