# P16: Typed structured output with validated citations and one repair retry

## Problem

A triage that cites evidence the run never collected, or code that is not in the bundle, reads as fact and misleads the on-call engineer. Schema-valid JSON does not prevent this, and a reply cut off at `max_tokens` or refused by a safety classifier is not an answer.

## What the template does

- **Request** (checked against the AWS and Anthropic docs on 2026-11-04): `invoke_model` on `bedrock-runtime`, so `converse` is not needed. The body is `anthropic_version: "bedrock-2023-05-31"`, `max_tokens` (16000), a `system` text block with `cache_control: {"type": "ephemeral"}`, one user message, and `output_config: {"effort": "medium", "format": {"type": "json_schema", "schema": ...}}`. Effort needs no beta header. There is no `temperature`, `top_p`, `top_k`, `tool_choice` or `thinking` field: Opus 5.5 always thinks adaptively, and effort is the control (P18).
- **Model ID**: on `bedrock-runtime` the bare `anthropic.claude-opus-5-5` runs in-Region only in `eu-west-2`. Elsewhere, set `APP_BEDROCK_MODEL_ID` to a profile such as `global.anthropic.claude-opus-5-5` or `us.anthropic.claude-opus-5-5`.
- **Schema**: `TriageAnalysis`'s JSON schema without the keywords that Bedrock rejects (`maxLength`, `minLength`, `maxItems`, `minItems`, numeric bounds). Every object keeps `additionalProperties: false`. Pydantic still checks every cap.
- **Bedrock's schema limits**: `minItems` 0 or 1 only, at most 12 optional and 16 union-typed properties. A new schema compiles for up to about 90 s on first use, so the read timeout is 300 s.
- **Validation**: the reply must parse as a `TriageAnalysis` within its caps. Each cited ID must be one the run collected, by membership. Each code citation must equal a collected snippet's path, lines and symbol; the symbol may be null.
- **Attempts**: an invalid reply, or `stop_reason == "max_tokens"`, gets one repair call with `Your previous reply was invalid: <errors>` appended. A second failure raises `AnalysisInvalid`, which is not transient. `refusal` returns no analysis and `refusal=True`.
- **Cache**: Opus 5.5 caches a prefix of at least 512 tokens, so the fixed system prompt is longer than that (P23).
