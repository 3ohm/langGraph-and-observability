# P14: No secrets or identity in `configurable`; a `context_schema`

## Problem

langchain-core copies primitive `configurable` values into the metadata of every traced run, so settings, tokens or a user's identity put there end up in LangSmith. Objects put in graph state end up in every checkpoint.

## What the template does

- `configurable` holds only `thread_id`, which is `str(run_id)`.
- The run's fixed inputs (the run, the target, the settings and the adapters) go in the graph's `context_schema`. `AgentSpec.make_context` builds it again for each invocation; it is never checkpointed and never traced.
- The settings and their secrets (`SecretStr`) reach the steps only through the context, so they stay out of traces and checkpoints; adapters read secrets from there.
- Trace metadata comes from `run_metadata`: run ID, dedup key, agent, cluster, environment, app version and git SHA, plus the input's namespace and workload. Never a secret, a DSN or the input itself.
